# Manual KPIs (optional)

The Screener export has no operating KPIs (bank asset quality, order books, volumes, ARPU...), no trade
payables, capex or shareholding. Put them in `data/manual/<TICKER>_kpis.csv` and the engine uses them. Each
archetype's KPI list (required and optional, with units) comes from `config/sectors/<archetype>.yaml`. A
blank template per archetype is in `templates/<archetype>_kpis.csv`, generated by
`python -m engine kpi-templates`. `COVERAGE.md` lists which company-years are filled; regenerate it with
`python -m engine kpi-coverage`.

## Format (v2)

```
metric,fiscal_year,value,unit,source_url,source_date,verified
gnpa_pct,FY26,1.15,%,https://www.example-bank.in/press-release-q4fy26.pdf,2026-04-18,N
advances_cr,FY26,2960000,Rs cr,https://www.business-standard.com/...,2026-04-18,N
```

- **`metric`**: a KPI id from the sector module (for example `gnpa_pct`, `order_book_cr`, `units_sold`), or one of the generic inputs listed below.
- **`fiscal_year`**: `FY26` = April 2025 to March 2026. Stock values are year-end (31 March); flows are full-year.
- **`value`**: leave it blank when no source states the value. Never estimate. Blank rows are ignored.
- **Percentages**: give them as percent numbers (`1.15` for 1.15%) with `unit` `%`. Any id ending in `_pct` is divided by 100.
- **`unit`**: free text, so it can note the basis (`Rs cr (consolidated)`, `% (period-end)`).
- **`source_url` / `source_date`**: required for every non-blank value. The date is the source's publication date (`YYYY-MM-DD`, `YYYY-MM`, or a year plus a note such as `2025 (annual report FY2024-25)`).
- **`verified`**: `Y` = the value was checked in the primary document. `N` = it was taken from the cited page without opening the primary document. `scoring.yaml: manual.use_unverified` (default true) decides whether `N` values are used.
- **As-of runs** ignore rows after the as-of year. KPI years before the first Screener year extend the timeline as KPI-only rows, which is how Yes Bank FY14-FY16 enter the FY18 blow-up test.
- The provenance of every KPI used (URL, date, verified) is written to the report (`analysis.json` sections `sector` and `manual_kpis`).

## Generic inputs (any archetype)

| metric | Used for |
|---|---|
| `trade_payables` (Rs cr) | DPO, cash conversion cycle |
| `short_term_borrowings` (Rs cr) | cash / short-term borrowings |
| `capex` (Rs cr) | replaces the balance-sheet capex proxy (FCF, reinvestment) |
| `exceptional_items` (Rs cr, pre-tax, + gain / - loss) | replaces the estimated exceptional item in other income |
| `minority_interest` (Rs cr, balance-sheet NCI) | added back to invested capital for ROIC |
| `promoter_holding_pct`, `promoter_pledge_pct` | promoter holding / pledge metrics and flags A02, A03 |
| `beta` | overrides the levered beta |

The Session 1 format (`period,kpi,value,unit,source`, with periods such as `FY25`, `Q2FY26` or a date) is
still read. The last observation in a fiscal year wins.
